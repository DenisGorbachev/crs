# Tap to quote

- Enable quoting by default and keep it enabled across quotes until toggled off.
- A tap on prose quotes the whole sentence, including text split by inline formatting. Links keep their normal action.
- A tap on code quotes the line. Preserve indentation and the language in a Markdown code fence.
- Append each quote to the draft as a Markdown blockquote. Focus the textarea on a blank line for the comment.
- Support keyboard activation of quote targets.
